PASO 1: GENERAR JWT_SECRET
================================================================================

Ejecuta en terminal:
$ node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

Resultado: Copia el valor (algo como: a7f3c9e2b1d4f6a8c5e9d2f7b4a8e1c3f6d9b2e5a8c1f4d7b0e3a6c9f2e5)

GUARDA ESTE VALOR - lo necesitas para Railway

================================================================================
PASO 2: DEPLOY BACKEND A RAILWAY
================================================================================

Opción A: Dashboard (más fácil)
---------
1. Ve a https://railway.app/dashboard
2. Click "New Project"
3. Selecciona "GitHub"
4. Busca y selecciona: hvilleg-dev/GrowAgentAI
5. Railway auto-detecta Node.js
6. Click "Deploy"
7. Espera a que termine

Opción B: CLI
---------
$ npm install -g @railway/cli
$ railway login
$ cd backend
$ railway up

Configurar variables de entorno EN RAILWAY DASHBOARD:
[ ] JWT_SECRET = <tu-valor-generado>
[ ] ANTHROPIC_API_KEY = <tu-key>
[ ] OPENAI_API_KEY = <tu-key>

(DATABASE_URL se crea automático)

Result: Backend URL (ejemplo): https://growagentai-backend-prod.railway.app

GUARDA ESTA URL - la necesitas para Vercel

================================================================================
PASO 3: DEPLOY FRONTEND A VERCEL
================================================================================

Opción A: Dashboard (más fácil)
---------
1. Ve a https://vercel.com/new
2. Selecciona "Import Git Repository"
3. Busca y conecta: hvilleg-dev/GrowAgentAI
4. Vercel auto-detecta Vite
5. Configuración:
   - Framework: Vite
   - Root Directory: frontend
   - Build: npm run build
   - Output: frontend/packages/web/dist
6. Environment Variables:
   [ ] VITE_API_URL = https://[tu-backend-url-de-railway]
7. Click "Deploy"

Opción B: CLI
---------
$ npm install -g vercel
$ vercel login
$ cd frontend/packages/web
$ vercel

Result: Frontend URL (ejemplo): https://growagentai.vercel.app

GUARDA ESTA URL

================================================================================
SOLUCIÓN DE PROBLEMAS
================================================================================

Error: "Cannot find module"
→ Verifica que package.json esté correcto
→ npm install en local primero

Error: 401 unauthorized
→ Verifica VITE_API_URL en Vercel env
→ Verifica JWT_SECRET en Railway env

Error: Connection refused
→ Espera 2-3 minutos después del deploy
→ Verifica que Railway backend esté corriendo

Error: CORS error
→ Backend CORS debe permitir tu dominio Vercel
→ Revisa backend/src/app.ts cors configuration
