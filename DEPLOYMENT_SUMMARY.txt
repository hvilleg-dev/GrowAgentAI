NEXT STEPS FOR USER
-------------------

1️⃣  Push code to GitHub (if not done):
    git push -u origin main

2️⃣  Create Railway PostgreSQL database
    Go to https://railway.app → New Project → PostgreSQL
    Copy CONNECTION_URL as DATABASE_URL

3️⃣  Deploy backend to Railway
    Set root directory: backend/
    Set environment variables (DATABASE_URL, OPENAI_API_KEY, etc.)
    Railway auto-deploys from GitHub

4️⃣  Deploy frontend to Vercel
    Go to https://vercel.com → Import Git Repository
    Set VITE_API_URL to Railway backend URL + /api
    Click Deploy

5️⃣  Test deployment
    Visit https://growagentai.vercel.app
    Login → Create Session → Send Message
    Verify bot responds with coaching + RAG context

⏱️  Estimated Time: 15-30 minutes
