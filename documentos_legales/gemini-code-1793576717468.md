# 🛑 POLÍTICA DE USO ACEPTABLE (AUP)
> **Normativa de Conducta**  

Quedará estrictamente prohibido utilizar el Agente Coach para:

1. Intentar burlar, evadir o manipular deliberadamente los guardrails de seguridad y detección de crisis ("jailbreaking").
2. Introducir contenido ilegal, acoso, discursos de odio, material de explotación o actividades fraudulentas.
3. Utilizar el software con fines de diagnóstico clínico automatizado en terceros sin supervisión humana calificada.
